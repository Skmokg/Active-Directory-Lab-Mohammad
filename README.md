# Active Directory Home Lab

### About This Project
This project demonstrates my ability to set up and manage an Active Directory environment using Windows Server and Windows 10. I configured a domain called *Mohammad.org*, joined a client machine, and managed users through Active Directory.

---

### Key Tasks Completed
- Installed **Windows Server 2019** and **Windows 10 Enterprise** using VirtualBox.
- Configured **Windows Server 2019** as a Domain Controller (DC).
- Set up and managed the domain *Mohammad.org* using Active Directory.
- Created a **Helpdesk** user account with administrative permissions.
- Connected **Windows 10 Enterprise** to the domain for centralized authentication and management.
- Configured static IP addresses via **Network and Sharing Center** for domain connectivity.

---

### Tools and Technologies
- VirtualBox
- Windows Server 2019
- Windows 10 Enterprise
- Active Directory
- Network and Sharing Center
- Command Prompt

---

### What I Learned
- Installing and configuring operating systems in a virtualized environment.
- Setting up and managing a domain with Active Directory.
- Joining client machines to a domain for centralized management.
- Basic IP configuration and troubleshooting for network connectivity.
